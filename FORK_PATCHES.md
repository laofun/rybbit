# Fork Patches

This document tracks every customization layered on top of `upstream/rybbit-io/rybbit`.
Read this before merging from upstream — it tells you which files have local edits
and how risky each one is.

## Branch model

```
master                   ← mirror of upstream/master, only fast-forward merges
heatmaps-integration     ← production branch = master + the patches below
```

Sync recipe:

```bash
git fetch upstream
git checkout master && git merge --ff-only upstream/master
git checkout heatmaps-integration && git rebase master
# resolve conflicts (use the table below to know where to look), then
cd client && npm install && npx tsc --noEmit
cd server && npm install && npx tsc --noEmit
cd server && npm run build:analytics       # regenerates public/script*.js
git push --force-with-lease origin heatmaps-integration
```

### D. Built analytics script artifacts

`server/public/script.js` and `server/public/script-full.js` are checked in by upstream and regenerated by `npm run build:analytics`. Whenever upstream rebuilds them or we change the analytics-script source, both sides will conflict.

**Workflow on merge conflict here**: keep upstream's version, then run `cd server && npm run build:analytics` and commit the rebuilt output as a separate commit on top.

## Merge-risk legend

- **None** — file does not exist upstream; merge cannot conflict.
- **Low** — small append, isolated hunk, marked with `# fork:` comment where helpful.
- **Medium** — a few lines inside a shared hunk; may conflict if upstream rewrites the same area.
- **High** — large or scattered edits; expect conflicts every other sync.

## When merging upstream

1. Run the sync recipe at the top of this file.
2. For each file with a "Medium" or "High" rating in the table, verify the merge actually preserved our intent (don't trust git's three-way result blindly).
3. Re-run `npx tsc --noEmit` on both `client/` and `server/` and start the dev servers to smoke-test the heatmap UI before pushing.
4. Update this document if the patch surface changes.
